# Definition of Done

Um item só pode ser marcado como concluído quando:

- critérios de aceite estão atendidos e vinculados ao item;
- implementação está em branch curta e PR revisável;
- typecheck, lint e testes acordados estão verdes;
- testes relevantes foram adicionados ou a ausência foi justificada;
- não há secrets, dados reais ou logs sensíveis;
- impacto em privacidade, RLS, migrations e autorização foi revisado;
- documentação e `.env.example` foram atualizados quando necessário;
- há evidência concreta: teste, captura, preview ou demonstração;
- o cliente validou comportamento visível ou decisão de negócio aplicável;
- débito ou limitação remanescente foi registrado no backlog/handoff.
